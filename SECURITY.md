# Security

Please report security problems privately, through this repository's **Security → Report a vulnerability** page, rather than in a public issue. Include what is affected, how to reproduce it, and the Flashwright version.

Flashwright is a fork of Playwright. If the problem also happens with stock Playwright of the same version, it is Playwright's: report it to Microsoft as described in [Playwright's security policy](https://github.com/microsoft/playwright/security/policy).
