Generated by `bun run inventory` from Playwright 1.60.0 declarations and reviewed claims. Edit [compatibility/parity-reviews.json](../compatibility/parity-reviews.json), then regenerate.

Flashwright remains an experimental Chromium implementation. These tables describe recorded development evidence, not release acceptance or a performance claim. Historical checkpoints retain their own runtime, platform and source limits.

The complete inventory contains 6425 entries: 0 supported, 466 experimental, 76 unsupported and 5883 planned/unverified. These counts include types, overloads, options and parameters; they are not a percentage of working features.
