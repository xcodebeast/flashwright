# Flashwright

Flashwright is building a Rust browser-testing engine with a TypeScript API compatible with a declared subset of Playwright. The goal is lower action and assertion latency and better complete-suite throughput while preserving real Chromium behavior

## R1 Current state

The [compatibility table](docs/compatibility.md) lists every pinned Playwright API entry and links reviewed development behavior, explicit rejections, missing methods and intentional differences to evidence. Unreviewed entries remain labelled unverified. Regenerate it with `bun run inventory`; `bun run inventory:check` rejects stale claims or tables, and `bun run test:inventory` checks the review boundaries.
