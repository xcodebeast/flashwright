# Ordinary retirement collection experiment

The [focused Linux checkpoint](../../benchmarks/results/ordinary-retirement-gc-linux-2026-10-21.json) tests one ordinary full collection at the existing retired-context boundary instead of one memory-reducing full collection. It is unadopted. Complete-suite performance and resource gates were not evaluated.

Apply [ordinary-retirement-gc.patch](ordinary-retirement-gc.patch) to the separate-browser baseline reconstructed from [the Linux recovery checkpoint](recovered-linux-2026-10-21/README.md), reversing its direct-shared native and Rust candidate patches as documented there. The source file's before/after hashes and browser/driver hashes are recorded in the checkpoint. The patch changes only `v8/src/api/context-retirement.cc`. Use the existing `tools/build-chromium.mjs` wrapper; the experiment and restoration each required one compilation and one link. This is incremental-build evidence, not a clean-build reproduction.

`FLASHWRIGHT_ORDINARY_RETIREMENT_GC=1` selects `kNoFlags` at the existing full collection. Without it, the original memory-reducing policy remains. `FLASHWRIGHT_RETIREMENT_GC_AUDIT=1` records the selected branch and collection count; it was enabled in these diagnostics. Existing single-collection selection, pressure handling, document/worker/broker retirement and zero-WebView checks remain. Ordinary collection permits background ArrayBuffer sweeping and retains more allocator memory; it does not simply remove compaction. Neither policy proves synchronous finalizer drainage.

Ten successful captures exercise 174 fresh contexts. The separately preserved initial pressure fixture completed its eight contexts but then failed a stale trace-file wait; removing that unrelated wait corrected the harness. Both policies pass the 48-context SVG document bound before a separate final diagnostic collection. Warm context-close medians in one diagnostic launch per mode are 11.95 ms and 11.55 ms. This small component observation does not establish suite savings. The candidate was deprioritized in favor of larger architectural work; it did not fail an evaluated suite-performance gate.

Raw fixtures, logs, screenshots and candidate binaries remain in ignored `workbench/ordinary-retirement-gc-001`. Baseline source and browser hashes were verified after restoration; the unchanged Rust driver was not rebuilt. Do not use this patch as a public default or treat these focused controls as full compatibility/resource admission.
