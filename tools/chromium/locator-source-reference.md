# Locator initializer source-reference experiment

The [Linux screen](../../benchmarks/results/locator-source-reference-linux-2026-10-21.json) rejects this composition against its predeclared complete-suite advancement gate. The patches preserve a private experiment; they are not enabled in the product.

Apply `locator-source-reference-native.patch` from the Chromium source root and `locator-source-reference-rust.patch` from the private Rust checkout. Their preimages are the separate-browser baseline obtained from the [recovered Linux sources](recovered-linux-2026-10-21/README.md) after reversing the direct shared-browser deltas. Check the five preimage SHA-256 values in the screen's `implementation.patchVerification` before applying. All five patched outputs were reconstructed and checked against the measured source hashes. Build with the existing S18 configuration and pinned dependencies; no new build arguments are needed.

`FLASHWRIGHT_CACHE_LOCATOR_SCRIPT=1` enables both sides. The Rust driver hashes the complete initializer and first requests its source by that key. A miss returns false and falls back to the original full-source evaluation under the same unique context and deadline. The native inspector retains at most one source string of 512 Ki UTF-16 code units, with no JavaScript handles, and evaluates a request-local copy through the existing debugger evaluation path. It rejects a different full source registered under the current key. The native side trusts the debugger client's digest; this is not a security boundary against clients with debugger access.

`FLASHWRIGHT_LOCATOR_CACHE_AUDIT=1` emits hit/miss/store and evaluation timing diagnostics. Leave it disabled for performance comparisons. The screen uses the same candidate browser and driver with caching off/on, reversed launch order, original workloads and fresh contexts, plus a separate stock Playwright reference. Startup and natural shutdown remain inside the complete-owner clock.

Realm, storage, trusted-input, graphics and actual video screenshot controls passed. The first-assertion diagnostic improved, but the complete-suite gate failed and one four-worker application observation regressed substantially. The preceding native sources, companion files and known browser/driver executables were restored. Broader lifecycle, platform, hardware-decoder, resource and release gates remain open.
